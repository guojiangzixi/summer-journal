## 三、这次做了什么防止第三次

1. **立刻建了 git 并提交事故基线**：
   ```bash
   cd F:\Doc\SummerJournal\code
   git init && git add -A && git commit -m "事故后基线 v1.2.0"
   ```
   从这一刻起，任何覆盖都能 `git diff` 看见、`git checkout` 撤回。
2. **同步规则（硬性）**：跨位置同步一律 `rsync -au --itemize-changes`，
   **禁止** `tar cf - . | tar xf -`、`cp -r`、`robocopy /MIR` 这类覆盖式操作。
3. **多会话并行**：先约定「谁负责哪些文件」，或各自开分支。
